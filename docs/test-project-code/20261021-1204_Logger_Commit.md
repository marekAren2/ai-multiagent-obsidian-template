# Commit loggera

## Opis

Commit `feat(logger): add typed logging helper` dodaje typowane API `get_logger(name: str, level: int = logging.INFO) -> logging.Logger`. Funkcja ustawia poziom przy każdym wywołaniu i dodaje sformatowany `StreamHandler` tylko wtedy, gdy logger nie ma handlerów. Powiązane notatki: [[20261021-1053_Logger]] i [[Workspace_Setup]].

## Weryfikacja

Smoke test uruchomiony z katalogu projektu wywołał `get_logger` dwukrotnie z poziomem `DEBUG` i potwierdził ten sam obiekt loggera, jeden handler oraz poziom `DEBUG`. Test przeszedł.
